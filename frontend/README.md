# Querywise frontend

React 19 + Vite chat UI for Querywise.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run lint
```

The UI expects the backend at `http://127.0.0.1:8000` (see `API` in `src/api.js`).

For the full project overview, architecture and setup, see the [root README](../README.md).
